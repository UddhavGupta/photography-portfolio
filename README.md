# Uddhav Gupta Photography

Static portfolio site. No build step.

- `index.html`: the page. Photos are listed in `PHOTOS` and ordered by `ORDER`.
- `img/full/NN.jpg`: large view (2400 px long edge)
- `img/thumb/NN.jpg`: grid thumbnails (1000 px long edge)
- `hero.mp4`: header video

Deployed on Vercel; every push to `main` goes live.
